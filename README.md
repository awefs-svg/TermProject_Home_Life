# 어서와, 우리집!

## 프로젝트 소개
농작물을 재배하고 판매해 코인을 얻고, 가구와 장식 아이템을 구매해 집과 마당을 꾸미는 웹게임입니다.

## 사용 기술
- Node.js
- Express
- HTML, CSS, JavaScript

## 실행 방법
1. Node.js 설치
2. 프로젝트 폴더에서 터미널 실행
3. 필요한 패키지 설치 ( npm install )
4. 서버 실행 ( npm start )
5. 브라우저 접속
